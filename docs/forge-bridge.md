# `window.Forge` – native capabilities for packaged web apps

Available only inside an app generated by Forge, on the app's own origin and only for the top-level page (not iframes).
Feature-detect it: `if (window.Forge) { ... }`. Every method returns a Promise. Only the capabilities you tick in the publish wizard exist.

| Method | Enabled by | Result |
|---|---|---|
| `Forge.requestPermission(name)` | any permission | `true` / `false` (`name`: `camera`, `microphone`, `location`, `notifications`) |
| `Forge.permissionStatus(name)` | same | `true` / `false` |
| `Forge.notify({ title, body })` | local notifications | `{ id }` |
| `Forge.share({ title?, text?, url? })` | share & links | `{}` – opens the Android share sheet |
| `Forge.openDialer(number)` | share & links | opens the phone app with the number filled in (user presses call) |
| `Forge.openSms(number, body?)` | share & links | opens the messages app with the text ready (user presses send) |
| `Forge.openUrl(url)` | share & links | `https:` or `mailto:` in the system app |
| `Forge.copyToClipboard(text)` | share & links | `{}` |
| `Forge.vibrate(ms)` | Vibration | `{}` (1–2000 ms) |
| `Forge.oauth(authorizeUrl)` | OAuth | `{ url }` – the redirect URL, with `code` / `state` / tokens |
| `Forge.redirectUri` | OAuth | string, e.g. `com.ahmed.shop://oauth` |
| `Forge.pushToken()` | FCM push | FCM registration token (string) |
| `Forge.subscribeTopic(t)` / `unsubscribeTopic(t)` | FCM push | `{}` |
| `Forge.googleSignIn({ nonce? })` | Google sign-in | `{ idToken, email, name, givenName, familyName, photo }` |
| `Forge.googleSignOut()` | Google sign-in | `{}` |

Errors are `Error` objects with `.code`: `CANCELLED`, `NO_CREDENTIAL`, `PERMISSION_DENIED`, `NOT_ENABLED`, `BAD_ARGS`, `FAILED`, `UNSUPPORTED`.

Events (window `CustomEvent`, data in `e.detail`): `forge:push` (`{ title, body, data }`) and `forge:pushToken` (`{ token }`).

Standard web APIs also work when the permission is ticked: `navigator.mediaDevices.getUserMedia`, `navigator.geolocation`, and `Notification`
(a polyfill that calls `Forge.notify`, since Android WebView has none).

## Why "open the dialer / messages" and not send/call directly?
Google Play restricts `SEND_SMS`, `CALL_PHONE` and call-log permissions to default phone/SMS apps. Opening the system app needs no permission,
is accepted by Play, and keeps the user in control.

## OAuth for any provider
```js
const state = crypto.randomUUID();
const url = 'https://github.com/login/oauth/authorize?client_id=XXX&redirect_uri=' + encodeURIComponent(Forge.redirectUri) + '&state=' + state;
const { url: redirected } = await Forge.oauth(url);   // opens a Chrome Custom Tab, returns when the provider redirects back
const params = new URL(redirected).searchParams;        // check params.get('state') === state, then exchange params.get('code') on YOUR server
```
Register `Forge.redirectUri` with the provider. Use the code flow with PKCE where the provider supports it; never put client secrets in the page.

## FCM push
Needs `google-services.json` (wizard: "Files and fingerprints"). Notification messages sent while the app is in the background are shown by Android;
data messages and foreground messages reach the page through `forge:push`. Send from Firebase Console → Messaging, or from your server with FCM HTTP v1 using the token from `Forge.pushToken()`.

## Google sign-in setup (what the wizard checks for you)
1. Google Cloud Console → Credentials: a **Web client** (its Client ID goes in Forge) and an **Android client** with your package id and SHA-1.
   Use the upload key's SHA-1 for builds you sign yourself, and the *App signing key certificate* SHA-1 from Play Console for the published app.
2. Verify `idToken` on your server (audience = the Web Client ID), or hand it to Firebase Auth with `GoogleAuthProvider.credential(idToken)`.

Google refuses OAuth in embedded WebViews (`disallowed_useragent`), which is why sign-in goes through Credential Manager or a Custom Tab.
In Forge's own preview there is no bridge; use the 🌐 button to test web flows in Chrome at `http://localhost:8080`
(add it to *Authorized JavaScript origins*).
